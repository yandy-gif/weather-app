# 气象观测台 · 使用说明

一个零依赖的天气应用：移动版（PWA，可装到手机主屏幕）+ 桌面仪表版（手机/电脑浏览器通用）。
数据来自 Open-Meteo，无需任何 API Key。

## 一、启动服务器（手机使用的前提）

- 双击 `start.bat`，窗口会打印本机与局域网访问地址。
- 已配置**开机自启**：启动目录里有快捷方式 `WeatherStation.lnk`，开机会自动最小化运行。
  - 撤销开机自启：删除
    `%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\WeatherStation.lnk`
- 停止服务器：关闭那个最小化的"气象观测台服务器"窗口。
- 端口被占用时新实例会自动退出，不会报错弹窗。

## 二、手机装成 App（主屏幕图标 + 全屏）

手机与电脑连同一 Wi-Fi，打开 `http://<电脑IP>:8090/`（页面底部有引导条）：

- **iPhone**：Safari → 底部「分享」→「添加到主屏幕」→ 添加
- **Android**：Chrome → 右上「⋮」→「添加到主屏幕 / 安装应用」→ 确认

装好后主屏幕出现独立图标（深靛坐标纸 + 朱红曲线），点开全屏无地址栏。
桌面仪表版界面：同地址后加 `desktop.html`。

## 三、功能

- 当前观测 + 24 小时自记曲线（实测靛蓝实线 / 预报朱红虚线 / 笔尖为当前时刻）
- 两地绑定对比（顶栏「A 主城市 / B 对比」切换编辑槽），温差与差异总结
- 穿搭建议（按体感分档，叠加风 / 降水 / 紫外线 / 湿度 / 昼夜温差修正）
- 读数盘 8 项、七日气温区间条、下拉刷新、每 15 分钟自动刷新、记住城市

## 四、已知限制

- 局域网 http 地址下浏览器不注册 Service Worker，故"电脑关机后离线看上次天气"不可用；
  如需离线与 Android 系统级安装提示，需改用 https（自签证书或内网域名）。
- 手机主屏幕图标指向电脑上的服务：电脑开机且服务器运行时体验完整。

## 五、文件

| 文件 | 作用 |
|---|---|
| index.html | 移动版 App 界面 |
| manifest.webmanifest / sw.js | PWA 清单 / 离线缓存 |
| icon.svg / icon-192.png / icon-512.png | 应用图标 |
| server.js / start.bat | 零依赖静态服务器 / 一键启动 |
| gen-icons.js | 图标生成器（node 运行可重新生成图标） |

桌面仪表版位于上级目录 `../weather.html`。
